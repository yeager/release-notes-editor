# Release Notes Editor

Release notes editor with templates and translation support.

Built with GTK4/Adwaita. Part of the [Danne L10n Suite](https://github.com/yeager/debian-repo).

## Installation

### Debian/Ubuntu
```bash
sudo apt install release-notes-editor
```
